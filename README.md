# Memory Match

A mobile-first PWA memory game (flip pairs). No dependencies, no build step.

## Run locally

```bash
python3 -m http.server 8080
```

Open http://localhost:8080 — installability (and the service worker) require `localhost` or HTTPS.

## Structure

```
index.html              shell + install prompt logic
style.css               mobile-first layout, card 3D flips, safe areas
game.js                 face library, sampling, board, matching, scoring
sw.js                   cache-first service worker (offline)
manifest.json           PWA manifest + shortcuts
icons/                  icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
faces/                  card faces — drop generated art here
faces/faces.json        library manifest; cards auto-listed if omitted
```

## Card faces

Drop images in `faces/` named `face-01.webp` (any count, webp/png/jpg/svg).
Filename only is the caption. Or declare them explicitly in `faces/faces.json`:

```json
{ "faces": [ { "file": "face-01.webp", "caption": "Apple" } ] }
```

Auto-listing picks up whatever count you generate — 4x4 samples 8 per game,
6x6 samples 18, so more faces = more variety. Faces load lazily per game.

## Icons

Placeholders are committed (`icons/`, generated by `tools/make-icons.sh`).
Replace with real art when ready; `icon-maskable-512.png` must keep art inside
the 40% safe zone (web.dev maskable-icon playground).
